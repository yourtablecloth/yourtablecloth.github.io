# 식탁보 AI Preview 사용과 개인정보 보호

2026년 9월 30일 현재 [v1.22.0-preview.5](https://github.com/yourtablecloth/TableCloth/releases/tag/v1.22.0-preview.5)는 식탁보 AI 창의 초기 크기를 메인 창과 맞추고 인증서 조회와 입력 보호 기능을 제공합니다. 이 안내는 Preview 기능의 현재 동작을 설명합니다. 정식 출시에서는 기능과 화면이 달라질 수 있습니다.

식탁보 AI는 사용자의 ChatGPT 로그인으로 OpenAI Codex 런타임을 사용합니다. 사용자가 메시지를 보내면 대화와 필요한 문맥이 OpenAI에 전달되며 구독 사용량이 적용됩니다. [개인정보 처리방침](/docs/privacy)에서 전달 항목과 로컬 진단 기록을 확인할 수 있습니다.

## 인증서 만료 건수만 전달하는 조회

사용자가 인증서 만료를 질문하고 조회에 동의하면 식탁보는 호스트의 기본 NPKI 폴더를 로컬에서 검사합니다. AI에는 이미 만료된 인증서 수, 향후 30일 안에 만료되는 인증서 수와 검사를 끝냈는지만 전달합니다. 일부 파일을 읽지 못하면 검사 결과가 불완전하다고 알립니다. AI는 개별 인증서의 이름, 발급자, 경로, 만료일과 스크린샷을 직접 확인할 수 없습니다. 인증서별 상태가 필요한 경우 AI 대화에 자료를 붙여 넣지 말고 기기의 인증서 관리 화면에서 확인할 수 있습니다.

## 항상 보이는 입력 주의 문구

AI 입력란 위에는 민감 개인정보, 공동인증서 파일과 스크린샷을 임의로 입력하거나 링크로 공유하지 말라는 문구를 계속 표시합니다. 입력창은 일부 국내 전화번호, 주민등록번호와 주소 패턴을 자동으로 가립니다. 인식 가능한 인증서 세부 정보 및 인증서 스크린샷 링크는 전송을 거부합니다. 파일 첨부 기능은 제공하지 않습니다. 정적 필터는 모든 표현과 외부 링크의 내용을 확인할 수 없으므로 가려지지 않은 개인정보가 전송될 수 있습니다.

## 대화 기록과 외부 서비스

식탁보는 현재 대화의 일부를 창이 열려 있는 동안 메모리에 유지하며 새 대화를 시작하거나 창을 닫으면 앱의 기록을 비웁니다. OpenAI 측의 처리와 보관은 [OpenAI 개인정보 처리방침](https://openai.com/policies/row-privacy-policy/)과 [계정 데이터 제어](https://help.openai.com/en/articles/7730893-data-controls-in-chatgpt)를 따릅니다. 식탁보의 로컬 대화 삭제가 OpenAI 측 데이터 삭제까지 수행하지는 않습니다. AI가 제안한 웹 링크를 열 때는 현재 Windows 브라우저와 Windows Sandbox 중 하나를 선택할 수 있습니다.
